# STATS C163 Generative Data Science Project

Task: Each team will design an agent.  Your agent will play repeated Prisoner's Dilemma matches against other agents in the tournament.
Your agent must repeatedly decide:
1. what message to send to the opponent;
2. whether to choose Cooperate or Defect in each round;
3. how to use history, memory, and rankings to improve long-term performance.

**Goal:**  after multiple tournaments, obtain as high a final ranking as possible
